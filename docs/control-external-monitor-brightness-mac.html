Control external monitor brightness on a Mac

macOS changes brightness only on Apple displays. For most other monitors you have to use the buttons on the monitor. DisplayLatch lets you change it from the menu bar instead, and it changes the monitor's real backlight.

How it works: DDC/CI

Most monitors support DDC/CI, a standard way for a computer to change the monitor's settings over the same cable that carries the picture. DisplayLatch sends the standard brightness command (VCP code 0x10), so the monitor really gets dimmer. That's different from a software overlay, which only darkens the image.

Steps

  1. Install DisplayLatch and click its menu-bar icon.
  2. Drag a monitor's Brightness slider, or use All displays to change every monitor at once.
  3. From Terminal: displaylatch brightness all 40 or displaylatch brightness <serial> 70.

Brightness doesn't change?

  • Turn on DDC/CI in the monitor's own on-screen menu. Some monitors turn it off by default.
  • Some docks, KVM switches and adapters don't pass DDC through. Test with a direct cable.
  • TVs and some portable monitors don't support DDC at all.

Frequently asked questions

How do I adjust the brightness of a second monitor on Mac?

Use a DDC app such as DisplayLatch. It controls the monitor's hardware brightness from the menu bar, with a slider per monitor or one slider for all displays.

Does DisplayLatch dim the screen with an overlay?

No. It uses DDC/CI to change the monitor's own backlight, the same setting the monitor's buttons change.
