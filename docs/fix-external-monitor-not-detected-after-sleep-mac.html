External monitor black or not detected after sleep on Mac

You wake your Mac and one external monitor stays black, or it's missing from the desktop. Unplugging it may not help, and the problem can come back after every restart. This guide shows how to find out whether the cause is physical or macOS, and how to fix each case.

Step 1: is it the cable or macOS?

Open System Information (hold Option and choose Apple menu › System Information), then select Graphics/Displays.

  • The monitor is not listed. The Mac doesn't see it at all, so the cause is physical. Reseat the cable at both ends, try another cable or port, check the monitor's input source and power, and remove any dock or adapter to test.
  • The monitor is listed but stays black, or displaylatch list shows it as OFFLINE. The Mac detects the monitor, but macOS is keeping it off the desktop. Read on.

Step 2: why macOS keeps a detected monitor off the desktop

WindowServer, the part of macOS that manages screens, decides which detected monitors join the desktop. It can store a monitor as an independent output or leave it disabled. The monitor then gets power and macOS reads its details, but it never gets a picture. WindowServer saves this, so the monitor can stay dark after every reboot. Display utilities that "disconnect" monitors, and the macOS option to stop extending to a display, can leave a monitor in this state.

Step 3: fix it

Quick things to try

  1. Put the displays to sleep and wake them (Control-Shift-Power, or close and open the lid), then wait 10 seconds.
  2. Unplug all external monitors, wait 10 seconds, and connect them again one at a time.
  3. Open System Settings › Displays and check that the monitor isn't mirrored and is set to Extended display.

If the monitor comes back but disappears again after the next sleep or restart, the stored state is the cause.

Fix it automatically with DisplayLatch

DisplayLatch is a free menu-bar app that checks for this after every display change, after wake and every 20 seconds. If it finds a monitor that is attached but off the desktop, it clears the independent-output flag, enables the display again and restores its position. To run the fix once from Terminal:

displaylatch fix

Any monitor you switched off on purpose in DisplayLatch stays off. It never wakes the built-in screen while the lid is closed.

Frequently asked questions

Why does my Mac not detect my external monitor after sleep?

If System Information doesn't list the monitor, the cause is physical: the cable, adapter, input or power. If it is listed but stays black, macOS WindowServer has kept it off the desktop, for example as an independent output, and DisplayLatch can bring it back automatically.

Why does my second monitor stay black but show as connected on my Mac?

macOS can keep a detected monitor off the desktop. The monitor gets power and is identified, but it receives no picture. The state is saved, so it can come back after every restart. Running 'displaylatch fix', or keeping DisplayLatch running, puts the monitor back on the desktop.

Do I need to delete windowserver plist files to fix a missing monitor?

Usually not. WindowServer often writes the same stored state back. DisplayLatch fixes it through the macOS display configuration instead, without deleting files or restarting.
